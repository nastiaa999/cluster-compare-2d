ClusterCompare 2D — документация исходного кода
===============================================

Программа сравнивает алгоритмы кластеризации двумерных данных: K-Means,
агломеративную кластеризацию со связью Уорда, DBSCAN и Mean Shift.
Документация сформирована автоматически из строк документации модулей.

Пакет ``cc2d.core`` содержит ядро (данные, предобработка, алгоритмы, метрики,
эксперимент, экспорт) и не зависит от графического интерфейса.
Соответствие классов ядра классам диаграммы уровня спецификаций (рис. 2.5 РПЗ)
приведено в описании пакета :mod:`cc2d.core`.
