# ClusterCompare 2D

Настольное приложение для сравнения алгоритмов кластеризации двумерных данных: K-Means, агломеративная кластеризация (связь Уорда), DBSCAN и Mean Shift. Программа загружает набор из файла CSV или генерирует синтетический, запускает до четырёх алгоритмов, показывает результаты на диаграммах рассеяния и сравнивает их по метрикам качества (силуэт, Дэвис–Болдин, Калински–Харабаш, ARI, NMI).

Курсовая работа по дисциплине «Технология разработки программных систем», МГТУ им. Н.Э. Баумана, кафедра ИУ6. Автор: А. С. Касатикова, гр. ИУ6-55Б. Руководитель: Е. С. Тверская.

Алгоритмы кластеризации реализованы вручную на NumPy. Библиотека scikit-learn используется только для генерации наборов, нормализации признаков, вычисления метрик и как эталон в тестах.

## Требования

- Windows 10 или 11 (64-разрядная)
- Python 3.11

## Установка и запуск

```
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m cc2d
```

## Тесты

```
.venv\Scripts\python -m pytest --cov=cc2d --cov-branch
```

Измерения времени на 5000 точках запускаются отдельно: `pytest -m slow`.

## Дистрибутив

```
.venv\Scripts\pyinstaller cc2d.spec --noconfirm
```

Готовая программа: папка `dist\ClusterCompare2D` (около 300 МБ), запуск `ClusterCompare2D.exe`. Папку можно целиком скопировать на другой компьютер с Windows 10 или 11, Python там не нужен. Журнал работы пишется в `%LOCALAPPDATA%\CC2D\cc2d.log`.

## Документация исходного кода

Формируется средством Sphinx из строк документации модулей; новые модули подхватываются автоматически:

```
.venv\Scripts\python -m sphinx -b html docs docs/_build/html
```

Результат: `docs/_build/html/index.html`.

## Структура

- `cc2d/core/` — ядро: источники данных, предобработка, алгоритмы, метрики, эксперимент, экспорт
- `cc2d/visualization.py` — диаграммы рассеяния
- `cc2d/gui/` — интерфейс: главное окно, окно сравнения, окно экспорта, справка
- `cc2d.spec` — настройки сборки дистрибутива PyInstaller
- `tests/` — тесты pytest
- `docs/` — документация Sphinx
